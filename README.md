# Reusable Actionlets for Open-World Robot Manipulation

An experimental framework for studying reusable robot manipulation skills and their adaptation to changing environments.

## Current Demo

The current prototype uses PyBullet and a Franka Panda robot to demonstrate physics-based pick-and-place manipulation.

Features:
- Eight-stage pick-and-place execution
- Step-by-step and automatic execution
- Robot-object contact monitoring
- Object state tracking and execution traces
- Interactive Gradio interface

## Research Direction

The long-term goal is to investigate how reusable action representations can support generalization and adaptation in open-world robotic manipulation.

Planned research includes:
- Reusable action representations
- Generalization to unseen objects and physical properties
- State-transition prediction
- Test-time skill adaptation
- Integration with robot foundation models

## Status

Early research prototype. The current demo is not yet a learned or adaptive robot policy.
